# Step Over (F8) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make F8 in the ElfBug Linux debugger actually step over `call`, `rep`-prefixed and `pushf` instructions instead of single-stepping into them.

**Architecture:** A third resume mode in `Debugger`, alongside the existing `PTRACE_CONT` and `PTRACE_SINGLESTEP` paths. At a stop, the instruction at RIP is classified with Zydis; if it is steppable-over, a non-singleshot INT3 is planted at `rip + length` and the tracee is continued. `handleSigtrap` decides whether a trap at that address completes the step (right thread, right stack frame), should be silently resumed past, or should cancel. Classification is a pure function over bytes so it unit-tests without a tracee.

**Tech Stack:** C++17, ptrace, Zydis v4 (via `src/zydis_wrapper`), CMake + cmkr, Catch2 v3.14.0.

**Spec:** `docs/superpowers/specs/2026-08-08-step-over-design.md`

```cpp
#include <ElfBug/process/StepOver.h>
#include <zydis_wrapper.h>

namespace ElfBug
{
    StepOverKind ClassifyStepOver(const uint8* bytes, const size_t n, const ptr rip, ptr & nextAddr)
    {
        nextAddr = 0;
        if(!bytes || n == 0)
            return StepOverKind::None;

        Zydis zydis(true);
        if(!zydis.Disassemble(rip, bytes, n))
            return StepOverKind::None;

        const ptr next = rip + zydis.Size();

        if(zydis.IsCall())
        {
            nextAddr = next;
            return StepOverKind::Call;
        }

        if(const auto* instr = zydis.GetInstr())
        {
            constexpr auto repMask = ZYDIS_ATTRIB_HAS_REP | ZYDIS_ATTRIB_HAS_REPE | ZYDIS_ATTRIB_HAS_REPNE;
            if((instr->info.attributes & repMask) != 0)
            {
                nextAddr = next;
                return StepOverKind::Rep;
            }
        }

        // Single-stepping sets EFLAGS.TF, which the tracee's own pushf would observe.
        switch(zydis.GetId())
        {
        case ZYDIS_MNEMONIC_PUSHF:
        case ZYDIS_MNEMONIC_PUSHFD:
        case ZYDIS_MNEMONIC_PUSHFQ:
            nextAddr = next;
            return StepOverKind::Pushf;
        default:
            break;
        }

        return StepOverKind::None;
    }
}
```

```cpp
    bool Debugger::stepPastBreakpointByte(const pid_t pid, const ptr addr)
    {
        if(!mProcess || !mThread)
            return false;

        mProcess->DeleteBreakpoint(addr);

        if(!mThread->StepInto())
        {
            cbInternalError("PTRACE_SINGLESTEP failed: " + std::string(strerror(errno)));
            mProcess->SetBreakpoint(addr, false);
            if(ptrace(PTRACE_CONT, pid, nullptr, nullptr) == -1)
                cbInternalError("PTRACE_CONT failed: " + std::string(strerror(errno)));
            return false;
        }

        int stepStatus = 0;
        pid_t waited = -1;
        do
        {
            waited = waitpid(pid, &stepStatus, __WALL);
        }
        while(waited == -1 && errno == EINTR);

        if(waited == -1)
        {
            cbInternalError("waitpid(step) failed: " + std::string(strerror(errno)));
            mProcess->SetBreakpoint(addr, false);
            return false;
        }

        mThread->clearSingleStep();

        if(WIFEXITED(stepStatus) || WIFSIGNALED(stepStatus))
        {
            const int code = WIFEXITED(stepStatus) ? WEXITSTATUS(stepStatus) : -WTERMSIG(stepStatus);
            if(pid == mMainPid.load(std::memory_order_relaxed))
            {
                exitProcessEvent(pid, code);
                mIsRunning.store(false, std::memory_order_release);
            }
            else
            {
                exitThreadEvent(pid);
            }
            return false;
        }

        if(WIFSTOPPED(stepStatus))
        {
            const int stepSig = WSTOPSIG(stepStatus);
            mThread->registers.Read();
            mProcess->SetBreakpoint(addr, false);

            if(stepSig != SIGTRAP)
            {
                if(ptrace(PTRACE_CONT, pid, nullptr,
                          reinterpret_cast<void*>(static_cast<uintptr_t>(stepSig))) == -1)
                    cbInternalError("PTRACE_CONT failed: " + std::string(strerror(errno)));
                return false;
            }
        }

        return true;
    }
```

```cpp
    bool Debugger::armStepOver(const pid_t pid)
    {
        cancelStepOver();

        if(!mThread || !mProcess)
            return false;

        const ptr rip = mThread->registers.Gip();
```

## Self-review notes

**Spec coverage.** Every numbered spec section maps to a task: §5.1 → Task 2; §5.6 `HasBreakpoint` → Task 3; §5.7 refactor → Task 4; §5.2-5.4 and §6.1 → Task 5; §6.2-6.4 → Task 6; §5.6 API and §5.8 GUI → Task 7; §8 build → Task 1; §9 testing → Tasks 2, 5, 6, 7.

**Two deliberate refinements of the spec**, both flagged inline where they occur:
1. The pure classifier is a free function `ElfBug::ClassifyStepOver`, not `Process::ClassifyStepOver`. It needs no instance; the memory-reading member is `Process::ClassifyStepOverAt`.
2. §6.1 implied completion is uniform. It is not: when we planted the INT3 we delete it and resume cleanly from the target, but when riding a user breakpoint the byte must stay `0xCC`, so we pre-execute via `stepPastBreakpointByte` exactly as a normal breakpoint stop does. Without this the resume immediately re-traps at the same address. Task 5 Step 8 implements both branches.

**Not covered by tests, by design (spec §10):** the free-running-thread race where `stepPastBreakpointByte` briefly restores the original byte. Pre-existing engine-wide, needs all-stop to fix.
